3 · Sensitivity

Shadow price yᵢ — the value of one more unit of resource i. Raise bᵢ by 1, the objective improves by yᵢ.
  • It is a derivative: z = yᵀb, so ∂z/∂bᵢ = yᵢ.
  • Economically: the most you'd pay for one extra unit.
  • Same object as: dual variable · simplex multiplier · opportunity cost · π.

RHS ranging

Perturbation — replace bᵢ by bᵢ + δ and ask how far δ can move.

Shifting bᵢ moves every basic value by δ × the entry in the sᵢ column (that column holds B⁻¹).

one inequality per basic row:
    RHS_row  +  δ · (sᵢ column entry)  ≥  0
  • Solve each for δ, intersect → the range where the basis stays optimal.
  • Uses only B⁻¹ and b — never c. Zero prices change nothing.

Degeneracy

Degenerate BFS — a basic variable equal to 0 in the RHS column.
  • The two endpoints of the RHS range are exactly the degenerate points. One table answers both questions.
  • The row whose inequality binds names the variable that hits 0 — and it is the one that would leave the basis.

Past the range

That variable leaves. Entering one by the dual ratio test: in the leaving row, among entries < 0, minimise |c'_j / row_j|. Then one pivot.

Cost ranging: for a basic variable, use its row under the non-basic columns and force every resulting Row-0 entry ≥ 0.

Weak & strong duality

Weak — cᵀx ≤ bᵀy for all feasible x and y. Every feasible dual is a ceiling on every feasible primal; they never cross.
Strong — cᵀx* = bᵀy* at optimality. The ceiling is actually reached; no duality gap.
  • Find x, y with cᵀx = bᵀy ⟹ both are optimal. One line.
  • "Show (P) is not unbounded" ⟹ exhibit one feasible dual point and check it; weak duality then caps (P). Squeeze both ways to pin z*.

  • 2. Constraint i has slack ⟹ yᵢ = 0.

Branching: on a fractional x_i = f, split into x_i ≤ ⌊f⌋ and x_i ≥ ⌈f⌉. No integer point is lost. Children inherit every ancestor constraint.

Closing a node — three rules

RuleCondition
integralityLP solution already integral → update Z* if better, then close
infeasibilitythe relaxation has no feasible point
boundZ_node ≤ Z* (max) · Z_node ≥ Z* (min)
  • A tie (Z_node = Z*) still prunes.
  • Integrality closes the node even when it improves — there's nothing left to split.
  • Record per node: node · constraint added · vertex · Z · which rule closed it.

Stopping the algorithm

  • Formally: the open list is empty → the incumbent is optimal. Never an incumbent → the IP is infeasible.
  • Early stop: as soon as every open node's bound cannot beat Z*.
  • Justify it in a sentence — "P₁ is integer with 14, above P₂'s 12.9, so above any child of P₂."

Node order

  • FIFO — queue, breadth-first, take the oldest open node.
  • LIFO — stack, depth-first, take the newest.
  • State which child you push first — the answer depends on it.

On a plot: empty region → prune by infeasibility, no arithmetic. Otherwise slide the objective line to the last vertex it touches.

7 · Total unimodularity

TU — every square submatrix has determinant in {−1, 0, +1}. Hence every entry is too.

TU + integral b ⟹ integral polyhedron ⟹ the IP solves in polynomial time.

Proving it

  • By recognition — the incidence matrix of a bipartite or directed graph is TU. Usually the whole answer.
  • Consecutive-ones (interval) matrices are TU.
  • By the three conditions:
    • entries in {−1,0,+1}
    • at most 2 non-zeros per column
    • rows split into M₁, M₂: same sign → different parts, opposite signs → same part

Do not write "Ghouila-Houri" — reproduce the three conditions.

Disproving it

Find a zero-free 2×2 with |det| ≥ 2. Any 2×2 containing a zero has det ∈ {−1,0,1}, so only zero-free blocks can break it.

Closure: A TU ⟹ −A, Aᵀ, A⁻¹, [A, I] are all TU.

8 · Matroids

Greedy finds the optimum for every weight function ⟺ the system is a matroid.

E — the ground set, a finite pile.
I ⊆ 2^E — the independent sets: which selections are allowed.

The three axioms

  • (1) ∅ ∈ I
  • (2) B ∈ I and A ⊆ B ⟹ A ∈ I  (hereditary)
  • (3) A, B ∈ I with |A| < |B| ⟹ ∃ x ∈ B\A with A ∪ {x} ∈ I

(1)+(2) alone = an independence system. Adding (3) makes it a matroid.

Basis

Basis — a MAXIMAL independent set: it is in I and cannot be extended.
  • bases ⊆ I. A basis is not extra structure — it's a member of I.
  • Maximal ≠ maximum. Maximal = cannot be extended (the definition). Maximum = largest possible size (the theorem).
  • Writing "the largest independent set" as the definition loses the mark.

All bases of a matroid have the same size — so here maximal ⟹ maximum.

To disprove: exhibit A, B ∈ I with |A| < |B| such that nothing in B\A extends A. Three elements is usually enough.

9 · Knapsack DP

B[i,w] — the best value using only items 1..i with capacity w.

Row 0 and column 0 are all zero: no items, or no room, means no value.

Recurrence — one decision per cell

if w_i ≤ w:
   B[i,w] = max{ B[i−1, w] ,           ← SKIP i
                 v_i + B[i−1, w−w_i] } ← TAKE i

if w_i > w:
   B[i,w] = B[i−1, w]        doesn't fit

Backtracking from (n, W)

  • B[i,w] = B[i−1,w] → item i not taken → go to (i−1, w)
  • otherwise → item i was taken → go to (i−1, w−w_i)

Complexity

Index byCost
weightO(n · W_max)

Run whichever bound is smaller, and say why. This is a marked step.

Pseudopolynomial, not polynomial: W is a number, written in log W bits, so O(nW) is exponential in the input length.

10 · Network flow

Flow — a number on every arc obeying:
capacity 0 ≤ f(e) ≤ u(e)
conservation in = out at every node except s and t

val(f) = Σ_j f(s,j) — the total leaving s, equal to the total arriving at t.

Cuts

Cut S = [X, V\X] with s ∈ X, t ∉ X.
cap(S) = Σ u(i,j) over i ∈ X, j ∉ X — forward arcs only.

Why forward only: capacity measures what could cross toward t. An arc pointing the wrong way carries nothing that direction, so it imposes no limit. Counting it inflates the cut.

val(f) ≤ cap(S)   every flow, every cut   ← weak
max val(f) = min cap(S)                   ← strong

Find a flow and a cut with the same number ⟹ both optimal. One line.

Residual network

  • Forward arc (i,j): capacity u(e) − f(e) — spare room.
  • Backward arc (j,i): capacity f(e) — flow you could undo.
  • Drop arcs of residual capacity 0.

The backward arc is the undo button — without it greedy path-finding is not correct.

Ford–Fulkerson

  • 1. Build the residual network.
  • 2. Find any s–t path. None left → the flow is maximal, stop.
  • 3. κ = smallest residual capacity on the path (the bottleneck).
  • 4. f += κ on forward arcs, f −= κ on backward arcs. Repeat.

Edmonds–Karp = the same, always taking a shortest path (BFS).
FF: O(|E|·U) pseudopolynomial · EK: O(V·E²) polynomial.

Reading the min cut for free

  • Take the final residual network (no augmenting path left).
  • X = every node reachable from s.
  • S = [X, V\X] is a minimum cut. Check cap(S) = val(f).

Modelling transformations

many sources/sinks → super-source and super-sink · node capacity → split v_in → v_out joined by an arc of that capacity · undirected edge → two opposite arcs

11 · TSP

EULER = every EDGE once (easy). HAMILTON = every NODE once (NP-complete).

TSP = a minimum-weight Hamiltonian cycle.

  • symmetric c_ij = c_ji → (n−1)!/2 tours
  • asymmetric → (n−1)! tours
  • metric c_ik ≤ c_ij + c_jk — both ratios below need it

The IP, in two stages

Degree constraints: Σ_{i≠j} x_ij = 1 ∀j and Σ_{j≠i} x_ij = 1 ∀i.

12 · Nonlinear, unconstrained

Critical point — a point where ∇f = 0. Maxima, minima and saddles all qualify, which is why you need the Hessian.
∇f = (∂f/∂x₁, …, ∂f/∂xₙ)ᵀ
H_f = (∂²f/∂xᵢ∂xⱼ)   — always symmetric

Procedure

  • Solve ∇f = 0 for all critical points — factor, don't divide. x·(…) = 0 has two branches.
  • Compute H_f symbolically.
  • Substitute each point separately — different points can classify differently.

Test A · 2×2 · det = ad − b², tr = a + d

dettrThe point is a
> 0> 0positive definite → minimum
> 0< 0negative definite → maximum
< 0—indefinite → saddle
= 0—inconclusive → Test C

Why: λ₁λ₂ = det, λ₁+λ₂ = tr. Same sign, or opposite.

Test B · leading principal minors

  • all D_k > 0 → positive definite → minimum
  • D₁<0, D₂>0, D₃<0, … alternating, starting negative → maximum
  • no D_k = 0 but neither pattern → saddle
  • any D_k = 0 → the test is inapplicable

Test C · eigenvalues — the fallback

Solve det(H − λI) = 0. All + → min · all − → max · mixed → saddle · some 0 → truly inconclusive.

A zero minor does NOT mean semidefinite — it means the test can't decide.

Do this FIRST

If H ≻ 0 everywhere (not just at the critical point) then f is strictly convex, so:

  • no maxima exist at all — a scoring statement, not a remark
  • any critical point is the unique global minimum

13 · Convexity

convex objective + convex feasible set ⟹ every LOCAL minimum is GLOBAL.

Convex SET — λx + (1−λ)y ∈ C for all x,y ∈ C, λ ∈ [0,1].
The whole segment between any two points stays inside.
Convex FUNCTION — f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y).
The chord between two points on the graph lies above the graph.
  • Strictly convex — < for x ≠ y. x² is; |x| is convex but not strictly.
  • Concave — reverse the inequality; equivalently −f is convex.
  • Affine aᵀx + b — both convex and concave (the chord is the graph).

Open / closed / bounded / compact

  • Open — every point has a small ball still inside. Strict <.
  • Closed — contains its own boundary; complement is open. Non-strict ≤.
  • Bounded — fits inside a finite box.
  • COMPACT = closed AND bounded (Heine–Borel, in ℝⁿ).
  • "Not open" ≠ "closed": [0,1) is neither, ℝⁿ is both.
  • On (0,1) the max is never attained — not closed. On [0,∞) it runs away — not bounded.

Weierstrass: non-empty compact set + continuous f ⟹ a global min AND max are attained.

Proving convexity

  • From the definition — when f is abstract or non-differentiable (a norm).
  • Hessian — on a convex domain: H ⪰ 0 everywhere ⟺ convex; H ≻ 0 everywhere ⟹ strictly convex (converse false — x⁴).
  • Composition — preserved by αf (α≥0), f+g, f(Ax+b), max{f₁..fₘ}, h∘g (h convex, non-decreasing).
  • Counterexample — one triple (x,y,λ) disproves it.

The norm proof — say every line

‖λx+(1−λ)y‖ ≤ ‖λx‖ + ‖(1−λ)y‖

14 · KKT

Standard form — convert first, always

min f(x)   s.t.  g_i(x) ≤ 0 ,  h_j(x) = 0

g(x) ≥ 0  becomes  −g(x) ≤ 0
max f     becomes  min −f
  • ACTIVE (tight, binding): g_i(x*) = 0 — the constraint presses.
  • INACTIVE (slack): g_i(x*) < 0 — room to spare.

The Lagrangian

L = f(x) + Σᵢ λᵢ gᵢ(x) + Σⱼ μⱼ hⱼ(x)    (MIN)

λᵢ  inequality  —  λᵢ ≥ 0  SIGN-CONSTRAINED
μⱼ  equality    —  free in sign

Why: violating gᵢ ≤ 0 must increase the objective you're minimising, so λ can't be negative. An equality breaks either way, so μ needs both signs. Same SOB pattern as §4. λ is a shadow price.

The four blocks

stationarity∇f + Σλᵢ∇gᵢ + Σμⱼ∇hⱼ = 0
primal feasibilitygᵢ ≤ 0, hⱼ = 0
dual feasibilityλᵢ ≥ 0
compl. slacknessλᵢ · gᵢ(x*) = 0

Solving — the case split

For each i: either λᵢ = 0 (inactive) or gᵢ(x*) = 0 (active).

  • Discard a case if λᵢ < 0 — dual infeasible.
  • Discard a case if gᵢ > 0 — primal infeasible.
  • Say why each branch died. It's scored.

Kill cases early using a fact in the problem statement — two distinct points exist ⟹ r > 0 ⟹ μr = 0 ⟹ μ = 0.

Slater vs LICQ — this decides your conclusion

RequiresGives you
Slaterf, gᵢ convex; hⱼ affine; a point x̄ with every gᵢ(x̄) < 0 strictlya KKT point IS a global optimum — stop
LICQactive ∇gᵢ plus all ∇hⱼ linearly independentcandidates only — evaluate f and compare
  • Verify Slater by exhibiting the point. Centroid with the radius inflated by +1, so every gᵢ ≤ −1 < 0. The +1 manufactures strictness.
  • Only equality constraints ⟹ Slater always fails — an equality has no strict version.
MC TRAP
  • "a KKT point is always a local optimum" — FALSE
  • "for a convex problem a KKT point is a global minimiser if Slater holds" — TRUE

The four-step recipe

  • 1. Existence — compact + continuous ⟹ a global min and max exist (Weierstrass). Cheap, often forgotten.
  • 2. CQ — Slater? otherwise LICQ.
  • 3. Solve — Lagrangian → 4 blocks → case split → discard, with reasons.
  • 4. Compare — evaluate f at survivors. Skip if Slater held.
